Wallet Bridge

How connection works

Wallet extensions normally inject providers into regular web pages, not extension pages. VEKTOR uses the X/Twitter tab as the bridge: this dashboard sends a request to the content script, the page asks MetaMask or another EVM wallet for accounts, then VEKTOR stores the public address and chain ID.
